# MyApp API

## Overview
MyApp API is an ASP.NET Core Web API project built using Clean Architecture.

## Technologies
- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server
- JWT Authentication
- Clean Architecture

## Features
- User Authentication
- JWT Authorization
- Task Management
- Repository Pattern
- Unit Of Work

## Project Structure

MyApp.API
MyApp.Application
MyApp.Infrastructure
MyApp.Domain
MyApp.Tests




## How To Run

1. Clone the repository
2. Update connection string
3. Run migrations
4. Run the API
